# 🏥 Apex Urgent Care & Wellness — Modern Healthcare Landing Page

A high-converting, mobile-first landing page built for local urgent care clinics, walk-in centers, and medical practices. Designed to build instant patient trust, showcase wait times, and simplify appointment bookings.

## 🚀 Live Demo
🔗 **[https://apex-urgentcare.vercel.app](https://apex-urgentcare.vercel.app)**

---

## ✨ Key Features
- ⚡ **Live Wait-Time Indicator:** Pulsing real-time banner displaying current clinic wait times.
- 📱 **Mobile-First UX:** Seamless drawer menu & responsive layout optimized for smartphone users booking on the go.
- 📅 **Interactive Appointment Modal:** Strict field validation (10-digit phone number limit, valid email check, compulsory symptom description) + single active booking limit. Routed directly to `adetito4life@gmail.com` via Formspree.
- ⭐ **Patient Testimonials Section:** Verified reviews, star ratings, and real patient feedback.
- 🗺️ **Google Maps Integration:** Embedded responsive interactive location map with quick directions link.
- 🏥 **Insurance Grid & FAQ:** Visual trust badges for accepted insurance providers + interactive FAQ accordion.

---

## 🛠️ Tech Stack
- **Frontend Framework:** React 18 + Vite + TypeScript
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Form Engine:** Formspree API (Routed to `adetito4life@gmail.com`)
- **Map Integration:** Google Maps Embed API

## 💻 Local Development Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/apex-urgentcare.git
   cd apex-urgentcare
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
